## Host it for FREE, forever — GitHub Pages (recommended)

1. **Create a GitHub account** (skip if you have one): https://github.com/signup

2. **Create a new repository**
   - Click the "+" top-right → "New repository"
   - Name it exactly: `YOUR-GITHUB-USERNAME.github.io`
     (replace with your actual username — this exact naming is what makes it free-hosted at the root domain)
   - Set it to Public → Create repository

3. **Upload your files**
   - On the new repo page, click "uploading an existing file"
   - Drag in `index.html` and `resume.pdf`
   - Click "Commit changes"

4. **Turn on GitHub Pages**
   - Go to repo Settings → Pages (left sidebar)
   - Under "Build and deployment" → Source: select "Deploy from a branch"
   - Branch: `main` (or `master`), folder: `/root` → Save

5. **Wait ~1-2 minutes**, then visit:
   `https://YOUR-GITHUB-USERNAME.github.io`

Your site is now live, and free forever — no credit card, no expiry, no server to maintain.
GitHub Pages is a genuinely permanent free tier (used by millions of personal sites).

## Making future edits
- Go to your repo → click `index.html` → click the pencil (edit) icon → make changes → "Commit changes"
- Site updates automatically within ~1 minute, no redeploy needed

## Optional: use a custom domain later
If you ever want `ajaykumarpatel.com` instead of the github.io URL, buy a domain (~$10-12/year from Namecheap/Cloudflare) and point it to GitHub Pages via repo Settings → Pages → Custom domain. Not required — the free github.io URL works perfectly fine on a resume.
